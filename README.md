  # Orchard Dataset and Supplementary Materials

  This repository provides the orchard dataset, partial publicly available code, and supplementary video materials used
  in our research work.

  ## Overview

  The repository contains materials related to orchard environment perception, navigation, and robotic operation
  experiments. These resources are provided to support reproducibility, result verification, and further research in
  agricultural robotics and orchard automation.

  ## Dataset

  The dataset was collected in orchard environments and is used in the experiments described in the associated paper. It
  includes data and materials related to orchard robotic navigation, perception, and field operation scenarios.

  Due to file size and publication constraints, only the data and resources that can be publicly shared are included in
  this repository.

  ## Code

  This repository contains part of the code that can be publicly released. Some implementation details or dependent
  components may not be included due to project, privacy, or publication restrictions.

  ## Supplementary Videos

  The upload/ directory contains supplementary video materials for demonstration and verification:

  - inspection video.mp4: orchard inspection demonstration
  - spray video.mp4: orchard spraying operation demonstration
  - navigation tower.jpg: field environment or platform image
  - picture.jpg: supplementary experimental image

  ## Usage

  The materials in this repository are intended for academic research and reference. Please check the file structure and
  related documentation before use.
